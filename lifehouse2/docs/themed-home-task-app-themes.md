## จุดร่วมของทุกธีม
- รูปแบบ isometric cutaway หลายห้อง/หลายชั้น
- มีตัวละครหลัก (เด็กผู้หญิง) และสุนัขขาว-ดำ เป็น mascot คงที่ทุกธีม
- ห้องประเภทเดียวกันในทุกธีม: พื้นที่ทำงาน (โต๊ะ+คอม), ห้องนอน, ห้องนั่งเล่น, ครัว/โต๊ะอาหาร, พื้นที่งานอดิเรก
- ป้ายธีม (ไอคอน + ชื่อ + "Theme") ใช้เป็นดีไซน์การ์ดสำหรับหน้าเลือกธีมได้เลย

## ข้อสังเกตสำหรับการออกแบบแอป
- Logic ของ task เหมือนกันทุกธีมได้ เปลี่ยนแค่ art/skin
- ห้อง/วัตถุสามารถแมปกับหมวดงานได้ (เช่น โต๊ะทำงาน = งานทำงาน, ครัว = งานบ้าน/มื้ออาหาร, ตู้อาร์เคด = mini-game)

## แนวทางต่อไป (ยังไม่ได้เลือก)
1. ต้นแบบหน้าเลือกธีม (HTML/PWA)
2. Hotspot mapping: ห้อง/วัตถุ ↔ หมวด task
3. Spec / data model: themes, rooms, tasks, rewards, mini-games
4. รีวิวภาพ: ความคงที่ของสไตล์, การอ่านง่ายบนมือถือ, ธีมเริ่มต้นที่เหมาะสม
