# CLAUDE.md — Amorn's Home (v2)

คู่มือหลักของโปรเจกต์ อ่านไฟล์นี้ก่อนเริ่มงานทุกครั้ง ตอบผู้ใช้เป็นภาษาไทย โค้ดและคอมเมนต์เป็นอังกฤษ
รายละเอียดเทคนิคเชิงลึก (โครงโค้ด พิกัด การทดสอบ กฎการแก้) อยู่ใน [`docs/TECHNICAL.md`](docs/TECHNICAL.md)

## โครงสร้างโปรเจกต์

```
lifehouse2/
  CLAUDE.md                 # ไฟล์นี้: ภาพรวม โครงสร้าง สรุป session
  build.sh                  # รวม parts/* -> index.html, site/index.html, artifacts/
  index.html                # ผลลัพธ์ (รูปแบบ artifact, ไม่มี doctype/head/body)   [สร้างจาก parts]
  parts/                    # ซอร์สที่แก้จริง (แก้ที่นี่เท่านั้น)
    a_head.html             # CSS + โครง HTML
    b1_core.js              # ข้อมูล ห้อง เวลา ตัวบ้าน
    b2_props.js             # ของตกแต่งและ props
    b3_world.js             # ตัวละคร เส้นทางเดิน
    b4_ui.js                # UI ทีวี กล้อง วนลูป __lh hook
  site/index.html           # เวอร์ชันไฟล์เว็บเดี่ยวสำหรับโฮสต์เอง          [สร้างจาก parts]
  artifacts/
    amorn-home.artifact.html  # สำเนาไฟล์ที่เผยแพร่เป็น artifact              [สร้างจาก parts]
  docs/TECHNICAL.md         # คู่มือเทคนิคภาษาอังกฤษ
  tests/
    run.js                  # Playwright runner: node run.js desk|phone steps.json
    steps_kitchen_office.json  # ภาพถ่ายใกล้ครัวและห้องทำงาน
    steps_tv_flow.json      # ทดสอบทีวี เควส สัปดาห์
    shots/                  # ภาพตัวอย่างล่าสุด (kitchen.png, office.png)
    package.json            # playwright-core + three@0.128 (รัน npm install ก่อน)
```

## วิธีทำงาน

1. แก้ไฟล์ใน `parts/` เท่านั้น ห้ามแก้ `index.html`, `site/index.html`, `artifacts/*` ตรงๆ
2. รัน `./build.sh`
3. ทดสอบ: `cd tests && npm install && node run.js desk steps_kitchen_office.json` (ได้ `desk []` แปลว่าไม่มี error) แล้วดูภาพใน `tests/shots/`
4. เผยแพร่ซ้ำ: publish ไฟล์ `/home/claude/lifehouse2/index.html` path เดิมเพื่อคง URL เดิม (ไม่ส่ง `icon`)
5. สำหรับโฮสต์เอง (Netlify / GitHub Pages ฯลฯ) ใช้ `site/index.html`

Artifact ที่เผยแพร่: https://claude.ai/artifact/7pou1tY6merXenwYEatqtC (Version 2)

## ฟีเจอร์ของบ้าน

- บ้านทรง mono-pitch สมัยใหม่ มีปุ่มเปิด/ปิดหลังคา
- ท้องฟ้า แสง และนาฬิกาในบ้านเปลี่ยนตามเวลาจริงของผู้ชม มีแถบเลื่อนเวลาให้ดูล่วงหน้า
- 9 พื้นที่: โรงรถ, ห้องทำงาน, ห้องนอน, ครัว, ห้องรับแขก, สวนหน้าบ้าน, ห้องออกกำลังกาย, ห้องน้ำ·สมาธิ, สระว่ายน้ำ
- ตัวละคร Amorn และสุนัข Border Collie เดินไปมาระหว่างห้อง นั่งทำงาน ออกกำลังกาย ทำสมาธิ ว่ายน้ำ และนอน (Amorn นอน 23:00–06:00)
- **แดชบอร์ดคือทีวีในห้องรับแขกเท่านั้น** ไม่มี side panel มีแท็บ เควส / โปรเจกต์ / สัปดาห์ / ถ้วยรางวัล / สรุป
- ชั้นถ้วยรางวัล 3D แสดงเหรียญที่คำนวณจากข้อมูล
- ตารางประจำสัปดาห์ของ gym / สมาธิ / สระ รีเซ็ตทุกวันจันทร์
- UI ภาษาไทย ใช้ได้ทั้งเดสก์ท็อปและมือถือ รองรับโหมดลดการเคลื่อนไหว
- ข้อมูลเก็บใน localStorage (`lifehouse.v2`) มีปุ่มคัดลอก JSON สำรอง ข้อมูลที่ใส่ไว้เป็นตัวอย่างทั้งหมด

## ลำดับงานใน session

1. ตกลงโจทย์ผ่านการสัมภาษณ์เรื่องแนวคิด ผังห้อง และตัวละคร (สองรอบ) แล้วสรุปเป็นโบรชัวร์ v2
2. สร้างและทดสอบ v2 ด้วย Playwright ทั้งเดสก์ท็อปและมือถือ แล้วเผยแพร่เป็น artifact ใหม่
3. **รอบแก้ล่าสุด:** ผู้ใช้บอกว่าครัวดูไม่เหมือนครัว และห้องทำงานควรมีคอมเครื่องเดียว พร้อมทีวี PS5 และโซฟา
   - ครัว: เพิ่มเคาน์เตอร์ซิงก์ เตา ตู้เย็น ตู้เก็บของ เกาะกลางพร้อมเก้าอี้ เคาน์เตอร์หลังพร้อมไมโครเวฟและเครื่องชงกาแฟ พรม และย้ายโปรเจกต์ไปอยู่บนโต๊ะอาหารกับบาร์
   - ห้องทำงาน: เหลือโต๊ะคอมเดียว เพิ่มมุมเล่นเกม (ทีวี, PS5, โซฟา, โต๊ะกาแฟ, พรม)
   - แก้บั๊กเล็ก (บรรทัดตั้งค่าต้นไม้ที่เรียกค่าที่ไม่มี) ทดสอบแล้วไม่มี error เผยแพร่ซ้ำที่ลิงก์เดิม
4. ทำไฟล์เว็บเดี่ยว `site/index.html` และแนะนำวิธีขึ้นเว็บ (Netlify Drop, GitHub Pages, Vercel, Cloudflare Pages)
5. เขียน `CLAUDE.md` ภาษาอังกฤษแบบละเอียด
6. เสนอธีมทางเลือก 11 แนว (ยังไม่ได้เลือกหรือลงมือทำ)

## ข้อควรรู้

- ต้องต่ออินเทอร์เน็ตเพราะโหลด Three.js r128 และฟอนต์จาก CDN
- ข้อมูลแต่ละเครื่องเก็บแยกกันในเบราว์เซอร์ ยังไม่มีการซิงก์ข้ามเครื่อง
- ห้องโครงการแต่ละห้องรับได้สูงสุด 6 โปรเจกต์ (ช่อง 7 จะถูกปฏิเสธ)
- ในครัวยังมีโน้ตบุ๊กบนโต๊ะอาหารและบาร์ เพราะเป็นตัวแทนโปรเจกต์ในห้องนั้น
- สคริปต์ทดสอบอยู่ใน `tests/` แล้ว (ต้องรัน `npm install` ใน `tests/` ก่อนใช้)
- โฟลเดอร์นี้อยู่ในคอนเทนเนอร์ชั่วคราวของ session ควรดาวน์โหลดทั้งโฟลเดอร์ (ไม่ต้องเอา `tests/node_modules`) เก็บไว้เอง
